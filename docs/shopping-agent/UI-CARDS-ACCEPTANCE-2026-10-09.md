# 前端展示与步骤卡片验收（2026-10-09）

本次按人工验收反馈调整用户、商家演示界面。

- 商家顶部只显示上次成功读取数据的时间。读取中、请求失败或响应校验失败均保留此前时间。
- 商家、目录、商品、报价、购买尝试和取餐地点的内部编号不进入可见展示；正常订单号保留，方便查询。
- 用户界面移除模型名称、HTTP/MOCK 技术标签及服务端配置提示；商家错误提示不带出后端编号或源码路径。
- 需求、候选、报价、订单分为四张横向滑动卡片。提交当前操作并获得有效结果后自动进入相应步骤；手动导航只允许返回当前卡片之前的步骤。
- 非活动卡片隐藏且不可获得键盘焦点。返回保留填写内容，后台刷新和报价计时不会把用户顶回后续步骤。
- 购买未知、处理中的尝试、未决发现失败和跨标签页未决记录仍限制新购买；恢复原购买的入口保留在卡片外。
- 页面重新获得焦点时，后台检查允许本地编辑和返回；购买动作继续等待检查完成。修复了首次点击输入控件被后台检查打断的问题。
- 确认请求失败但查询证明尚未形成购买尝试时，保留原报价并返回报价卡片，避免出现空订单卡片。
